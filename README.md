# CLIKEA

Le jeu des noms IKEA : une photo, deux noms, quatre noms ou aucun. 109 produits, 20 tirés au sort, cinq langues.

- **Jouer** : https://clac1212.github.io/clikea/ (puis https://clikea.is-a.dev)
- **Niveaux** : facile (45 produits connus), moyen (109 produits), difficile (cash uniquement, aucune proposition).
- **Points** : 1 en duo, 3 en carré, 5 en cash. Maximum 100.
- **Classement** : public, 20 meilleurs scores par niveau.

Page unique, sans dépendance ni build. Photos produit pointées sur le CDN d'ikea.com ; les noms et les prix sont ceux du catalogue français.

Pastiche non officiel, sans lien avec IKEA.
